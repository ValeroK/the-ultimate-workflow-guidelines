Layout and text on real data:
1. In CSS Grid, a `1fr` track has an automatic minimum (min-content), so it does not shrink below its content; `minmax(0, 1fr)` lets it shrink. (CSS Grid Layout 1, flexible lengths; MDN `minmax()`)
2. `flex-shrink` defaults to 1, and `flex-shrink: 0` keeps a flex item from shrinking below its flex basis. (CSS Flexbox 1; MDN `flex-shrink`)
3. `overflow-wrap: anywhere` permits breaks inside an otherwise unbreakable string and, unlike `break-word`, counts those soft wrap opportunities when computing the min-content size. (CSS Text 3; MDN `overflow-wrap`)
4. `word-break: break-all` allows a line break between any two characters of non-CJK text, inside ordinary words included. (CSS Text 3; MDN `word-break`)
5. The HTML standard warns against relying on the `title` attribute because many user agents do not expose it in an accessible manner (for example to keyboard-only and touch users). (HTML standard, the title attribute)
6. `-webkit-line-clamp` takes effect only together with `display: -webkit-box` (or `-webkit-inline-box`) and `-webkit-box-orient: vertical`. (MDN `line-clamp`; CSS Overflow 4)
7. `String.prototype.charAt(0)` and `str[0]` return one UTF-16 code unit, so for a character outside the Basic Multilingual Plane (most emoji) they return a lone surrogate. (MDN `String.prototype.charAt`)
8. `Intl.NumberFormat` applies locale-specific grouping and decimal separators; `de-DE` groups with "." and uses "," for decimals. (MDN `Intl.NumberFormat`)
9. `font-variant-numeric: tabular-nums` selects figures of equal width. (MDN `font-variant-numeric`; CSS Fonts 4)
10. `Intl.RelativeTimeFormat` formats past and future offsets per locale, and with `numeric: "auto"` produces phrases such as "yesterday" instead of "1 day ago". (MDN `Intl.RelativeTimeFormat`)
11. `Intl.DateTimeFormat` uses the runtime's default time zone unless a `timeZone` option is given, while `Date.prototype.toISOString()` always returns UTC. (MDN `Intl.DateTimeFormat`, `Date.prototype.toISOString`)
12. `object-fit: cover` scales replaced content to fill the box while keeping its aspect ratio and clips the rest; the initial value `fill` stretches it. (MDN `object-fit`; CSS Images 3)
13. An `<img>` whose image fails to load fires an `error` event. (HTML standard, the img element; MDN `HTMLImageElement` error event)

Viewport, safe areas and zoom:
14. `vh` resolves against the large viewport; `svh`, `lvh` and `dvh` resolve against the small, large and dynamic viewport, and `dvh` changes as browser interface such as the address bar expands and retracts. (CSS Values and Units 4, viewport-percentage lengths; MDN `<length>`)
15. On iOS, `env(safe-area-inset-*)` is 0 unless the viewport `<meta>` includes `viewport-fit=cover`. (CSS Environment Variables 1; MDN `env()`; WebKit blog "Designing Websites for iPhone X")
16. `env()` takes an optional fallback value as its second argument. (MDN `env()`)
17. `text-size-adjust: none` (`-webkit-text-size-adjust: none`) can stop users from zooming text in some browsers, and `100%` is the value that disables inflation without that effect. (MDN `text-size-adjust`)
18. iOS Safari zooms the page when focus lands on an input whose computed font size is below 16 px. (WebKit or Apple developer documentation) (may be secondary only)

The on-screen keyboard:
19. The viewport `<meta>` key `interactive-widget` takes `resizes-visual` (the default), `resizes-content` or `overlays-content`, and Chrome on Android supports it from version 108. (developer.chrome.com "Prepare for viewport resize behavior changes coming to Chrome on Android"; CSS Viewport Module 1)
20. `window.visualViewport` fires `resize` when the on-screen keyboard changes the visual viewport. (MDN `VisualViewport`)
21. The VirtualKeyboard API (`navigator.virtualKeyboard.overlaysContent`, `env(keyboard-inset-height)`) is available only in Chromium-based browsers. (MDN VirtualKeyboard API)
22. The `inputmode` attribute takes `none`, `text`, `decimal`, `numeric`, `tel`, `search`, `email` and `url`. (HTML standard, inputmode)
23. `enterkeyhint` takes `enter`, `done`, `go`, `next`, `previous`, `search` and `send`, and `autocapitalize` takes `none` (or `off`) to turn capitalisation off. (HTML standard, enterkeyhint and autocapitalize)

Touch and pointer input:
24. On touch devices, tapping an element applies `:hover`, which stays until the user taps another element. (WebKit or Safari Web Content Guide, "Handling Events") (may be secondary only)
25. The `hover` and `pointer` media features describe the primary input mechanism; `any-hover` and `any-pointer` describe any available input. (Media Queries 4; MDN `hover`, `any-hover`)
26. In Tailwind CSS v4 the `hover:` variant applies only inside `@media (hover: hover)`; in v3 the `future.hoverOnlyWhenSupported` flag gives that behaviour. (tailwindcss.com, v4 upgrade guide and hover documentation)
27. `-webkit-tap-highlight-color` is non-standard and is supported by Safari on iOS and Chrome on Android. (MDN `-webkit-tap-highlight-color`)
28. `touch-action` names what the browser may still handle: `pan-y` leaves vertical panning to the browser, `none` disables browser panning and zooming on the element, and `manipulation` allows panning and pinch zoom but not double-tap zoom. (MDN `touch-action`; Pointer Events 3)
29. Browsers do not delay `click` by about 300 ms for double-tap detection on pages with `width=device-width` or on elements with `touch-action: manipulation`. (developer.chrome.com "300ms tap delay, gone away"; WebKit blog "More Responsive Tapping on iOS")
30. `Element.setPointerCapture()` retargets later events of that pointer to the element, even when the pointer leaves it, until it is released or the pointer is lifted. (MDN `setPointerCapture`; Pointer Events 3)
31. `overscroll-behavior: contain` stops scroll chaining to ancestors while keeping the element's own overscroll effect; `none` also removes that effect. (CSS Overscroll Behavior 1; MDN `overscroll-behavior`)
32. Safari needs the `-webkit-user-select` prefix for `user-select`. (MDN `user-select`, browser compatibility)
33. `navigator.vibrate()` is not supported in Safari on macOS or iOS. (MDN `Navigator.vibrate`, browser compatibility)

Orientation, window sizes and focus:
34. 1.3.4 Orientation (AA): content does not restrict its view and operation to a single display orientation unless that orientation is essential. (Understanding 1.3.4)
35. `screen.orientation.lock()` is not supported in Safari and, where supported, generally requires fullscreen. (MDN `ScreenOrientation.lock`)
36. On iPad, Split View and Slide Over run apps, Safari included, in windows narrower than the screen, down to a compact width class like a phone's. (Apple Human Interface Guidelines, Layout and Multitasking)
37. The `orientation` media feature compares the viewport's width and height, not the device's physical orientation. (MDN `orientation` media feature; Media Queries 4)
38. Browsers match `:focus-visible` on keyboard focus but not when a button is focused by a mouse click, while a text input matches on any focus. (Selectors 4, `:focus-visible`; MDN)

Motion that breaks:
39. When a running CSS transition is interrupted by a new style change, the new transition starts from the current value, and reversing a partly finished transition is shortened accordingly. (CSS Transitions 1; MDN Using CSS transitions)
40. Removing an animation and applying it again restarts it from its first keyframe. (CSS Animations 1; MDN Using CSS animations)
41. `transitionend` is not dispatched when no transition runs (for example `transition: none` or a zero duration) or when the transition is removed before it completes, in which case `transitioncancel` fires. (CSS Transitions 1, events; MDN `transitionend`)
42. `animationend` is not dispatched for an animation that never runs, for example under `animation: none`. (CSS Animations 1, events; MDN `animationend`)
43. With `animation-fill-mode: forwards`, removing the animation (`animation: none`) returns the element to its base style. (CSS Animations 1; MDN `animation-fill-mode`)
44. A transition to or from `height: auto` does not interpolate unless `interpolate-size: allow-keywords` or `calc-size()` is used, and `interpolate-size` is supported in Chromium from 129 but not in Firefox or Safari. (MDN `interpolate-size`)
45. 2.2.2 Pause, Stop, Hide (A): moving, blinking or scrolling information that starts automatically, lasts more than five seconds and is presented in parallel with other content has a mechanism to pause, stop or hide it, unless it is essential. (Understanding 2.2.2)
46. Whether `:active` matches a focused button while the Space key is held is defined by the user agent, not guaranteed by the standard. (HTML standard, Selectors section, `:active`; MDN `:active`)
47. Radix Accordion exposes the open content's height as the CSS variable `--radix-accordion-content-height`. (radix-ui.com, Accordion)
48. Motion's `<MotionConfig reducedMotion="user">` disables transform and layout animations when the operating system asks for reduced motion. (motion.dev, MotionConfig)

Motion guidance:
49. Percentages in `translate()` refer to the size of the element's own reference box. (CSS Transforms 1; MDN `translate()`)
50. Base UI sets a `--transform-origin` CSS variable on popups so they can animate from their trigger. (base-ui.com, popover and menu documentation)
51. `@starting-style` defines starting values for a transition on an element's first style update, and is supported from Chrome 117, Safari 17.5 and Firefox 129. (MDN `@starting-style`)
52. UIScrollView's normal deceleration rate is 0.998, the value Apple's WWDC 2018 "Designing Fluid Interfaces" sample uses to project momentum. (developer.apple.com, `UIScrollView.DecelerationRate.normal`; WWDC18 session 803)
53. Apple's Human Interface Guidelines advise reducing or avoiding large-scale and repetitive motion for people sensitive to motion. (Apple Human Interface Guidelines, Motion and Accessibility)

56. `prefers-contrast` takes `no-preference`, `more`, `less` and `custom`. (MDN `prefers-contrast`; Media Queries 5)
57. `<meta name="theme-color">` accepts a `media` attribute so a page can give one colour per colour scheme, and `<meta name="color-scheme" content="light dark">` declares both schemes. (HTML standard, standard metadata names; MDN)
58. The initial value of `font-optical-sizing` is `auto`. (MDN `font-optical-sizing`)
59. Sonner's `<Toaster />` defaults `theme` to `light` and `dir` to `ltr`. (sonner.emilkowal.ski, Toaster API)
