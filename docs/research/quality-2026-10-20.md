Extra facts from the same pages:

- `go test` ignores files whose names begin with `_` or `.`, so a file named `_test.go` never runs.
- `pytest.raises(Exception)` matches subclasses, so it catches almost anything; use a specific type or `match=`.
- Mocha `--forbid-pending` fails on skipped tests; `--fail-zero` fails when no tests ran; `--pass-on-failing-test-suite` (10.7.0) exits 0 despite failures.
- `node:test`: `only` has an effect only with `--test-only` or test isolation off, and then it skips the rest.
- pytest-rerunfailures: a marker's `reruns` takes priority over `--reruns` unless `--reruns-mode=append`.
- Hypothesis raises `HealthCheck.function_scoped_fixture` for a function-scoped fixture under `@given`: it resets once per test, not per input.
- fast-check `configureGlobal()` replaces all global settings unless the previous ones are spread in.

## Our assessment of the reply

- **Item 26 changes a rule.** "The judge is not the model under test" stays as our reasoning [O] (a model grading its own output is an unchecked confound), but it is no longer presented as an established bias, and the "different model family" form is dropped. The calibration requirement (agreement with labelled cases) is what carries the weight.
- Items 4, 7, 19 rest partly on a truncated page or an issue tracker; their confirmed parts are used, the missing values are not.
- Several exceptions describe local debugging, which is out of scope anyway (items 10 to 12); not carried over.
- Version axes: Mocha 12 (`forbid-only` in CI), Playwright 1.52 (`failOnFlakyTests`), Mocha 10.7 (`--pass-on-failing-test-suite`), Python and pytest's strict-xfail option name.
